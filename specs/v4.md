# v4 Spec: Daily Journal

## Overview

v4 adds a **Daily Journal** tool to the performance tracker platform. The journal uses a morning/evening split with three prompts:

1. **Morning** — "What would success look like today?" (free text)
2. **Evening** — "Did I achieve that?" (yes/no toggle + free text elaboration)
3. **Evening** — "What was my performance out of 10? If not 10, what can I do to get to 10?" (1–10 score excluding 7, plus free text)

The morning entry is created first; the evening fields are filled later in the day. Users can also backfill and edit past entries.

**User decisions:**
- Performance score uses the same 1–10 scale (excluding 7) as the energy audit
- Backfill and editing of past entries is supported
- "Did I achieve that?" uses a yes/no toggle with optional free text elaboration

  └── Fully completed → Read-only view of both sections
        ├── [Edit] morning → edit morning form
        └── [Edit] evening → edit evening form

  ├── List of past entries

## Phase 2 — Database Schema + API

### 2.1 Prisma Schema

Add to `prisma/schema.prisma`:

```prisma
model JournalEntry {
  id               Int      @id @default(autoincrement())
  date             DateTime
  createdAt        DateTime @default(now())
  successVision    String                                  // Morning: "What would success look like today?"
  achieved         Boolean?                                // Evening: Yes/No
  achievedNote     String?                                 // Evening: elaboration
  performanceScore Int?                                    // Evening: 1–10 (excluding 7)
  improvementNote  String?                                 // Evening: "What can I do to get to 10?"
  userId           String
  user             User     @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([userId, date])
  @@index([userId, date])
}
```

### 2.3 Database Functions

Add to `lib/db.ts`:

```typescript
// Create a morning journal entry
export async function createJournalEntry(
  userId: string,
  data: { successVision: string },
  date?: Date
) {
  const entryDate = date ?? toMidnightUTC(new Date());
  return prisma.journalEntry.create({
    data: { ...data, userId, date: entryDate },
  });
}

// Get today's journal entry
export async function getTodayJournalEntry(userId: string) {
  const today = toMidnightUTC(new Date());
  return prisma.journalEntry.findUnique({
    where: { userId_date: { userId, date: today } },
  });
}

// Get all journal entries (with optional month filter)
export async function getAllJournalEntries(userId: string, month?: string) {
  const where: Prisma.JournalEntryWhereInput = { userId };
  if (month) {
    const [year, mon] = month.split("-").map(Number);
    const start = new Date(Date.UTC(year, mon - 1, 1));
    const end = new Date(Date.UTC(year, mon, 1));
    where.date = { gte: start, lt: end };
  }
  return prisma.journalEntry.findMany({
    where,
    orderBy: { date: "desc" },
  });
}

// Get journal entry by date
export async function getJournalEntryByDate(userId: string, date: Date) {
  return prisma.journalEntry.findUnique({
    where: { userId_date: { userId, date } },
  });
}

// Update journal entry by ID (for evening completion or edits)
export async function updateJournalEntryById(
  userId: string,
  id: number,
  data: {
    successVision?: string;
    achieved?: boolean | null;
    achievedNote?: string | null;
    performanceScore?: number | null;
    improvementNote?: string | null;
  }
) {
  return prisma.journalEntry.update({
    where: { id, userId },
    data,
  });
}
```

### 2.4 API Routes

**`POST /api/journal`** — Create morning entry (`app/api/journal/route.ts`)

Request body:
```typescript
{
  successVision: string;       // required
  date?: string;               // "YYYY-MM-DD" — omit for today
}
```

Validation:
- `successVision` must be a non-empty string → `400` if missing
- If `date` provided: validate `YYYY-MM-DD` format, reject future dates → `400`
- Check for existing entry on that date → `409 "A journal entry already exists for this date"`

Response: `201` with created `JournalEntry`

**`GET /api/journal`** — List entries (`app/api/journal/route.ts`)

- Optional `?month=YYYY-MM` query param
- Validate month format → `400` if invalid
- Returns array of `JournalEntry`

**`GET /api/journal/today`** — Today's entry (`app/api/journal/today/route.ts`)

- Returns today's `JournalEntry` or `null`

**`PUT /api/journal/[id]`** — Update entry (`app/api/journal/[id]/route.ts`)

Request body:
```typescript
{
  successVision?: string;
  achieved?: boolean | null;
  achievedNote?: string | null;
  performanceScore?: number | null;     // 1–10 excluding 7
  improvementNote?: string | null;
}
```

Validation:
- If `performanceScore` provided: must be in `[1,2,3,4,5,6,8,9,10]` → `400`
- If `successVision` provided: must be non-empty string → `400`
- Parse `id` from route params → `400` if not valid integer
- Catch Prisma `P2025` → `404 "Entry not found"`

Response: updated `JournalEntry`
